## Компания

**«Клиника Плюс»** — условная сеть частных медицинских клиник: 3 филиала в Москве, 45 врачей (терапевты, педиатры, узкие специалисты), около 6 000 приёмов в месяц.

## Как сейчас

Пациент записывается на приём **только по телефону**. Звонок принимает администратор филиала, который смотрит расписание врачей в МИС (медицинской информационной системе) и вручную вносит запись. За день до приёма администраторы обзванивают пациентов для напоминания.

## Проблемы

Исходные данные кейса (условные, как если бы их собрали на интервью и из отчётов телефонии):

| # | Проблема | Показатель | Последствие |
|---|---|---|---|
| P1 | Пациенты не могут дозвониться | 18% звонков в часы пик остаются без ответа | Пациент уходит в другую клинику |
| P2 | Долгая запись | 4,5 мин в среднем на звонок | Очередь на линии, усталость администраторов |
| P3 | Неявки | 14% записанных пациентов не приходят | Простой врачей, потерянная выручка |
| P4 | Администраторы перегружены | ~40% рабочего времени уходит на телефон | Меньше внимания пациентам в холле |
| P5 | Нельзя записаться вечером | 23% пропущенных звонков приходятся на нерабочее время | Спрос не обрабатывается |

**Оценка потерь:** 14% неявок × 6 000 приёмов × средний чек 3 200 ₽ ≈ **2,7 млн ₽ в месяц** неиспользованной ёмкости врачей.

## Цель проекта

Запустить **онлайн-запись через сайт и мобильную версию сайта**, интегрированную с МИС, с автоматическими напоминаниями и возможностью отменить или перенести запись.

## Метрики успеха (через 6 месяцев после запуска)

| Метрика | Сейчас | Цель |
|---|---:|---:|
| Доля записей онлайн | 0% | ≥ 40% |
| Доля неявок | 14% | ≤ 8% |
| Пропущенные звонки | 18% | ≤ 7% |
| Время администратора на телефоне | ~40% | ≤ 25% |
| Время записи для пациента | 4,5 мин + ожидание | ≤ 2 мин |

## Заинтересованные стороны

| Стейкхолдер | Интерес | Влияние |
|---|---|---|
| Генеральный директор (спонсор) | Рост выручки, снижение неявок | Высокое |
| Главный врач | Корректное расписание, отсутствие накладок | Высокое |
| Старший администратор | Снижение нагрузки, понятный процесс | Среднее |
| Пациенты | Быстро и в любое время записаться | Среднее |
| ИТ-отдел / подрядчик МИС | Безопасная интеграция, нагрузка на МИС | Высокое |
| Юрист | Соблюдение 152-ФЗ о персональных данных | Среднее |

## Границы проекта

**Входит в первую версию (MVP):**
- запись к врачу онлайн (выбор филиала, специальности, врача, времени);
- вход по номеру телефона с кодом из SMS;
- личный кабинет: мои записи, отмена, перенос;
- напоминания по SMS за 24 часа и за 2 часа;
- синхронизация расписания с МИС.

**Не входит (следующие версии):**
- онлайн-оплата приёма;
- телемедицина;
- запись на анализы и процедуры;
- мобильное приложение.

## Допущения и ограничения

- МИС клиники предоставляет REST API для чтения расписания и создания записей.
- SMS отправляются через существующий договор с SMS-провайдером.
- Персональные данные хранятся только в МИС; сервис записи хранит минимум (телефон, ФИО, ID пациента в МИС).
- Бюджет и сроки: MVP за 3 месяца.
